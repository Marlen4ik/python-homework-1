# Что такое Git?

**Git** — это распределённая система контроля версий, которая позволяет отслеживать изменения в файлах и управлять разными версиями проекта.

Git особенно полезен при разработке программного обеспечения, поскольку позволяет сохранять историю изменений, возвращаться к предыдущим версиям и работать над одним проектом совместно с другими разработчиками.

## Для чего нужен Git?

- **Контроль версий** — сохраняет историю изменений проекта.
- **Возврат к предыдущим версиям** — позволяет восстановить файлы, если что-то пошло не так.
- **Совместная работа** — помогает нескольким разработчикам работать над одним проектом.
- **Ветвление (Branches)** — позволяет создавать отдельные ветки для разработки новых функций, не затрагивая основной код.

## Основные понятия Git

- **Repository (Репозиторий)** — хранилище проекта и его истории изменений.
- **Commit (Коммит)** — сохранённый набор изменений.
- **Branch (Ветка)** — отдельная линия разработки проекта.
- **Merge (Слияние)** — объединение изменений из разных веток.
- **Clone (Клонирование)** — создание локальной копии удалённого репозитория.

# Как клонировать проект с GitHub

**Клонирование (Clone)** — это процесс создания локальной копии удалённого Git-репозитория на своём компьютере.

Это позволяет скачать проект с GitHub, работать с его файлами и вносить собственные изменения.

## 1. Скопируйте ссылку на репозиторий

1. Откройте нужный репозиторий на [GitHub](https://github.com/).
2. Нажмите зелёную кнопку **Code**.
3. Выберите SSH.
4. Скопируйте появившуюся ссылку.

## 2. Настройка SSH для GitHub

**SSH (Secure Shell)** — это протокол безопасного соединения, который позволяет компьютеру взаимодействовать с GitHub с помощью SSH-ключей.

Настройка SSH позволяет работать с репозиториями, выполнять `git clone`, `git push` и `git pull` без постоянной авторизации через браузер или ввода учётных данных.

### Инструкция по настройке SSH

**Как настроить SSH для GitHub:**

[Ссылка на статью](https://habr.com/ru/articles/1006970/)

### Проверка подключения

После настройки SSH можно проверить соединение командой:

```bash
ssh -T git@github.com
```

Если всё настроено правильно, GitHub сообщит об успешной аутентификации.

### Важно!

При клонировании репозитория через SSH необходимо скопировать именно SSH-ссылку.

Для этого:
1. Откройте репозиторий на GitHub.
2. Нажмите кнопку **Code**.
3. Выберите вкладку **SSH**.
4. Скопируйте ссылку.

Пример:

```bash
git clone git@github.com:username/project.git
```

# Как сделать Fork проекта на GitHub

## Что такое Fork?

**Fork (форк)** — это создание собственной копии чужого репозитория на своём аккаунте GitHub.

Форк позволяет:
- Создать собственную копию проекта.
- Вносить изменения, не затрагивая оригинальный проект.
- Добавлять новые файлы и удалять ненужные.
- Предлагать свои изменения автору оригинального проекта через Pull Request.


## 3. Создание Fork

1. Откройте нужный репозиторий.
2. В правом верхнем углу нажмите кнопку **Fork**.
3. На открывшейся странице нажмите **Create fork**.
4. Дождитесь завершения создания копии.

Теперь в вашем аккаунте появится собственный репозиторий.

## 4. Проверка Fork

После создания Fork вы попадёте в свою копию проекта.

Обратите внимание:
- Название репозитория должно совпадать с оригинальным.
- В адресе страницы должно быть имя вашего GitHub-аккаунта.
- Под названием репозитория будет указано, что он был создан на основе оригинального проекта (forked from).

## 5. Откройте терминал

Откройте терминал (Command Prompt, PowerShell или Terminal) и перейдите в папку, в которую хотите скачать проект.

Для этого используйте команду:

```bash
cd путь/к/папке
```

## 6. Выполните клонирование

Введите команду:

```bash
git clone ССЫЛКА_НА_РЕПОЗИТОРИЙ
```

Например:

```bash
git clone git@github.com:НИК/ССЫЛКА_НА_РЕПОЗИТОРИЙ
```

После выполнения команды Git скачает проект в новую папку.

## 7. Перейдите в папку проекта

```bash
cd project
```

Теперь вы находитесь внутри склонированного проекта и можете работать с его файлами.

## Полезные команды

| Команда | Описание |
|---|---|
| `git clone` | Клонирование репозитория |
| `git pull` | Получение последних изменений |
| `git status` | Проверка состояния файлов |
| `git log` | Просмотр истории коммитов |
