# Как отправить проект на GitHub (Push)

## 1. Что такое Push?

**Push** — это отправка изменений из локального проекта на компьютере в удалённый репозиторий на GitHub.

Например, вы создали проект на компьютере, добавили новые файлы или изменили код. Чтобы эти изменения появились на GitHub, нужно выполнить команду `git push`.

## 2. Подготовка

Перед началом убедитесь, что:

- У вас установлен Git.
- У вас есть аккаунт на GitHub.
- Вы авторизованы в GitHub.
- Вы создали репозиторий на GitHub или сделали Fork чужого проекта.
- Локальный проект связан с удалённым репозиторием.

## 3. Откройте терминал в папке проекта

Перейдите в папку своего проекта и откройте терминал.

Проверьте, что Git работает:

```bash
git status
```

Эта команда покажет состояние файлов проекта.

## 4. Добавьте изменения

Чтобы подготовить все изменённые и новые файлы к отправке, выполните:

```bash
git add .
```

Точка означает, что будут добавлены все изменения в текущей папке проекта.

## 5. Создайте коммит

Коммит — это сохранённая версия изменений с описанием того, что вы сделали.

Выполните команду:

```bash
git commit -m "Добавил новый функционал"
```

Вместо `Добавил новый функционал` напишите короткое описание своих изменений.

Например:

```bash
git commit -m "Добавил решение задач"
```

## 6. Отправьте проект на GitHub

Теперь отправьте изменения в удалённый репозиторий:

```bash
git push origin main
```

Здесь:
- `origin` — название удалённого репозитория.
- `main` — название ветки, в которую отправляются изменения.

Если ваша основная ветка называется `master`, используйте:

```bash
git push origin master
```

## 7. Проверьте результат

1. Откройте свой репозиторий на GitHub.
2. Обновите страницу.
3. Убедитесь, что новые файлы и изменения появились в репозитории.

Готово! Ваш проект отправлен на GitHub.
