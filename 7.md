# Как создать Pull Request на GitHub

## 1. Откройте свой репозиторий на GitHub

1. Перейдите на сайт GitHub.
2. Откройте свой Fork.
3. Убедитесь, что последние изменения появились в репозитории.

## 2. Создайте Pull Request

1. Перейдите во вкладку **Pull requests**.
2. Нажмите кнопку **New pull request**.
3. Проверьте, какие репозитории выбраны для сравнения.

Обычно должны быть указаны:

- **Base repository** — оригинальный репозиторий, в который вы хотите отправить изменения.
- **Head repository** — ваш Fork, из которого отправляются изменения.

Также проверьте ветки:

- **Base** — ветка оригинального проекта, например `main`.
- **Compare** — ваша ветка с изменениями, например `main`.

Пример:

```text
Base repository: author/project
Base: main

Head repository: my-username/project
Compare: main
```

4. Нажмите **Create pull request**.

## 3. Заполните описание Pull Request

Укажите:

**Title** — короткое название изменений.

Например:

```text
Добавил решения задач по Python
```

**Description** — описание того, что вы сделали.

Например:

```text
В этом Pull Request:

- Добавлены решения пяти задач.
- Исправлены ошибки в коде.
- Добавлены комментарии к решениям.
```

После заполнения нажмите **Create pull request**.

## 4. Проверьте созданный Pull Request

После создания вы попадёте на страницу своего PR.

На этой странице можно:

- Посмотреть отправленные изменения.
- Читать комментарии других участников.
- Отвечать на замечания.
- Вносить исправления в код.

Если автор проекта попросит что-то исправить, внесите изменения на компьютере, создайте новый Commit и выполните Push в ту же ветку.

**Важно:** новый Pull Request создавать не нужно. Изменения автоматически появятся в уже существующем PR.

## 5. Что происходит после создания Pull Request?

Автор оригинального проекта проверяет ваши изменения.

Возможны три варианта:

1. **Approve** — изменения одобрены.
2. **Request changes** — автор просит внести исправления.
3. **Merge** — изменения объединены с оригинальным проектом.

Если автор принимает ваш PR и нажимает Merge, ваши изменения становятся частью оригинального проекта.

---

## 6. Полная последовательность работы

Если вы хотите внести изменения в чужой проект, последовательность будет следующей:

1. **Fork** — создать копию чужого репозитория в своём аккаунте GitHub.
2. **Clone** — скачать свой Fork на компьютер.
3. **Edit** — внести изменения в проект.
4. **Add** — подготовить изменения к коммиту.
5. **Commit** — сохранить изменения.
6. **Push** — отправить изменения в свой Fork на GitHub.
7. **Pull Request** — предложить автору оригинального проекта принять изменения.
